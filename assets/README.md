# 📦 Pasta de Assets — Como Substituir os Modelos/Sprites

Esta pasta foi organizada para facilitar a substituição dos protótipos visuais por artes finais da dupla.

## 📁 Estrutura de Diretórios:

- **`res://assets/maquina/`**:
  - Contém as instruções e texturas da **Máquina** central ("Máquina Final").
  - O nó principal do jogo está em `res://scenes/maquina.tscn`.
- **`res://assets/players/`**:
  - Sprites e animações do **Player 1** (Fauth / Sala Esquerda) e **Player 2** (Knopp / Sala Direita).
  - A cena base do jogador está em `res://scenes/player.tscn`.
- **`res://assets/stations/`**:
  - Sprites e ícones das estações de reparo e falhas:
    - **Terminal**: Computador/painel de controle superior.
    - **Cabo / Fiação**: Cabos de energia com faíscas.
    - **Bobina / Mola**: Bobina de pressão que superaquece (conforme rascunho).
    - **Válvula**: Tubulação e registro de vapor.
  - A cena base das estações está em `res://scenes/repair_station.tscn`.
